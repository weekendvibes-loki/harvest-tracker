# docs/architecture

This folder contains system architecture documentation.

## Contents

- System architecture diagrams (Mermaid, PNG, SVG)
- Architecture Decision Records (ADRs)
- Component and sequence diagrams
- Deployment architecture diagrams

## Architecture Decision Records (ADR)

ADRs document significant design decisions. Use the naming convention:

```
ADR-001-feature-first-architecture.md
ADR-002-flyway-migration-strategy.md
```

Each ADR should cover:
- Context — why this decision was needed
- Decision — what was decided
- Consequences — what this enables or trades off
