# Harvest Tracker Documentation

## Project Goal

Provide a practical, phase-based playbook for building Harvest Tracker, a web application for seasonal mango farms that can later evolve into a multi-fruit harvest management platform.

## Purpose of This Folder

This folder contains the full documentation set needed for another AI agent or development team to implement the project without needing repeated clarification.
